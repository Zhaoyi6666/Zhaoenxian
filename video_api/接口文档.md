# 渔船作业姿态视频分析 API 交付说明

## 一、启动方式
1. 需要一台带 NVIDIA GPU（建议显存 >= 24G）的服务器，Python 3.8+ 环境。
2. 安装依赖：pip install -r requirements.txt
3. 启动服务：python video_api_server.py
4. 服务默认监听 http://0.0.0.0:8002 ，接口路径 /infer_video
5. 调用日志会自动记录到 logs/video_api_call.jsonl 文件中。

## 二、接口调用规范
- 请求方式：POST
- 请求头：Authorization: Bearer <WANWU_API_KEY>
- 请求体：multipart/form-data，字段名 file（视频文件，建议为10-30秒的纯作业片段）

## 三、返回结构 (HTTP 200)
返回JSON示例如下：
{
  "answer": "该渔船正在进行拖网作业。",
  "extras": {
    "posture": "放网姿态",
    "gear_type": "拖网",
    "duration_analyzed": 26.8,
    "frames_analyzed": 16
  }
}
