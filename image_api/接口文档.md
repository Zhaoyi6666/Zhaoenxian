# 渔船目标检测模型 API 交付说明（最终版）

## 一、模型优化说明
本次交付模型在原有 11 类检测模型基础上，利用新清洗的 33 张高质量样本，采用“冻结主干+强数据增强”策略进行了微调优化。
优化后模型指标：Precision=0.863, Recall=0.780, mAP50=0.897, mAP50-95=0.616。

## 二、部署与启动方式
1. 需要一台带 NVIDIA GPU 的服务器，Python 3.8+ 环境。
2. 安装依赖：pip install -r requirements.txt
3. 启动服务：python api_server.py
4. 服务默认监听 http://0.0.0.0:8001，接口路径 /infer

## 三、接口调用规范
- 请求方式：POST
- 请求头：Authorization: Bearer <WANWU_API_KEY>
- 请求体：multipart/form-data，字段名 file（图片，支持 JPG/PNG，≤10MB）

## 四、返回结构 (HTTP 200)
返回JSON示例如下：
{
  "answer": "检出 2 个目标。",
  "extras": {
    "empty": false,
    "count": 2,
    "image_width": 1920,
    "image_height": 1080,
    "detections": [
      { "label": "渔船", "confidence": 0.91, "bbox_xyxy": [120, 80, 640, 520] }
    ]
  }
}
